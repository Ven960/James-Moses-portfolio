Hospital Management System

The Hospital Management System is a multi-user application designed to help hospitals manage their daily operations efficiently.

The system provides different modules for managing patients, doctors, appointments, medical records, pharmacy, billing, laboratory services and administrative operations.

Technologies Used

Python MySQL HTML CSS JavaScript

Main Features

  • Patient registration and management
  • Doctor account management
  • Appointment scheduling
  • Medical records management
  • Pharmacy management
  • Billing and payments
  • Laboratory management
  • Administrative dashboard
